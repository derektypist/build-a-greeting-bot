# Build a Greeting Bot

Learn JavaScript Fundamentals by building a greeting bot.  Learn about variables, `let`, `const`, `console.log` and basic string usage.

## Technologies

Uses JavaScript.

## Deployment

Copy `script.js` to the text editor.  Use the command `node script.js`.

Or Clone the repository to Visual Studio Code.
